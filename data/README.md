# もりけん × 雷神 会話コンテンツ

会話は2種類あり、**データファイルが別々**です。混ざりません。

| | ファイル | どこに出るか |
|---|---|---|
| もりけんと雷神の話 | `data/conversations.js` | ページ中ほどのセクション。読みにいくもの |
| マスコットのひとこと | `data/bubbles.js` | 画面の隅のマスコット。押されたら単発で喋る |

以下は `conversations.js` の説明です。ふきだしは末尾の「ふきだし」の項を参照してください。

## 会話を追加するときに編集するファイル

```
data/conversations.js
```

**このファイルだけ**です。index.html も、その他の設定ファイルも触りません。

## 追加のしかた

`window.LS_CONVERSATIONS` の配列に、末尾から1件足します。

```js
{
  id: 'ai-002',                 // カテゴリー-連番3桁。重複禁止。公開後は変更しない
  category: 'ai',               // 下の一覧にあるキー
  title: '見出しになる一言',
  lines: [
    { speaker: 'raizin',  text: '雷神のせりふ' },
    { speaker: 'moriken', text: 'もりけんのせりふ' }
  ]
}
```

- `speaker` は `raizin`（雷神）か `moriken`（もりけん）の2つだけ。
  英字表記は **RAIZIN** です。RAIJIN ではありません。
- `lines` は何往復でも構いません。長文でも折り返して表示されます。
- 並べた順が、そのカテゴリー内の表示順になります。
- `id` は将来リンクの目印に使う想定なので、公開後は変更しないでください。

## カテゴリー

同ファイル冒頭の `LS_CONVERSATION_CATEGORIES` で定義しています。

現在は11カテゴリー・145件です。並べた順がタブの順番になります。

| キー | 表示名 | 件数 |
|---|---|---|
| `about` | 会社のこと | 15 |
| `spirit` | 会社の芯 | 10 |
| `ai` | AIのこと | 20 |
| `support` | AI活用の伴走 | 10 |
| `robot` | ロボットのこと | 15 |
| `dx` | アプリ・DXのこと | 15 |
| `combo` | AI × ロボット × 人 | 10 |
| `education` | 教育のこと | 10 |
| `faq` | よくある質問 | 20 |
| `daily` | 日々のこと | 10 |
| `future` | これからのこと | 10 |

新しいカテゴリーが要るときは、この表に1行足すだけです。
**会話が0件のカテゴリーは画面に出ません**（タブも生えません）。

## 追加したあとの確認

ブラウザで開いて、DevTools のコンソールを見てください。
書式に問題があると `[会話]` から始まる警告が出ます。

- `IDが重複しています`
- `未定義のカテゴリー`
- `speaker は raizin か moriken だけです`
- `項目が不完全です`

該当する会話だけが表示から外れ、**他の会話やページ本体は壊れません**。

## 自動検査

`main` へ push すると、GitHub Actions が `scripts/check.js` を走らせます
（`.github/workflows/check.yml`）。数秒で終わり、**デプロイは行いません**。

検査に引っかかると、GitHub上でそのコミットに赤いバツが付き、
Actions のログに日本語で理由が出ます。

- 会話データが JavaScript として読めない（カンマや括弧の閉じ忘れ）
- id の重複、id の形式ちがい
- 未定義のカテゴリー
- speaker が `raizin` / `moriken` 以外
- title や text が空
- HTMLが参照している画像・スクリプトのパス切れ
- 会話の中に `RAIJIN` の綴り

手元でも同じ検査ができます（Nodeが入っている場合）:

```
node scripts/check.js
```

なお、検査が赤くなっても**サイトの公開は止まりません**。
GitHub Pages は従来どおり main の中身をそのまま配信します。
検査はあくまで「気づくため」のものです。

## 表示条件

**画面幅を問わず、どの端末でも表示されます。**
2026-08-18に `mobile.html` を廃止し、index.html が全幅を担当する方針にしたためです。
以前ここに書いてあった「PCのみ表示」は、その時点で事実ではなくなりました。

幅によって変わるのは、見え方だけです。

| 幅 | ちがい |
|---|---|
| 900px 以下 | ふきだしと余白を詰める（既存のブレークポイント） |
| 700px 以下 | 先頭の会話を開いた状態にしない（縦に長くなりすぎるため） |

新しいブレークポイントは足していません。

会話データが1件も読めなかったときは、セクションごとDOMから取り除きます。

## ファイルが大きくなってきたら

1カテゴリーが20件を超えたあたりで、表示の絞り込み（ページ送りなど）を足すのが良い頃合いです。
また `data/conversations.js` は `concat` で追記する書き方にしてあるため、

```
data/conversations/about.js
data/conversations/ai.js
```

のようにカテゴリー別へ分割しても、**各ファイルの中身はそのままの書式で動きます**
（分割時は index.html に script タグを足す作業が一度だけ必要です）。

# マスコットのひとこと・かけあい

## 編集するファイル

```
data/bubbles.js
```

画面の隅にいる雷神・もりけんが、**押されたときに言う**内容です。3つの入れ物があります。

| | 内容 | 件数 |
|---|---|---|
| `raizin` | 雷神がひとりで言うこと | 15 |
| `moriken` | もりけんがひとりで言うこと | 15 |
| `pairs` | ふたりの一言かけあい（1往復） | 67 |
| `chats` | ふたりの雑談（何往復でも） | 110 |

せりふは画面下中央のウィンドウに**1行ずつ**出るので、往復数の制限はありません。
ただし往復が多いほどウィンドウが出ている時間は長くなります。

「もりけんと雷神の話」（`data/conversations.js`）は**読ませたい会話**の担当です。
2026-08-19に「ふたりの雑談」「ゆるい話」をこちらへ移しました。

## 追加のしかた

```js
window.LS_BUBBLES = {
  raizin:  [ 'ぼくも一緒に\nがんばるよ💪' ],
  moriken: [ '今日もいい仕事\nできそうな予感🔥' ],
  pairs: [
    { raizin: '保存した？',
      moriken: '……今する。' }
  ],
  chats: [
    { id: 'chat-201', title: '見出し（表示はされません）',
      lines: [
        { speaker: 'raizin',  text: '雷神のせりふ' },
        { speaker: 'moriken', text: 'もりけんのせりふ' },
        { speaker: 'raizin',  text: 'さらに続く' }
      ] }
  ]
};
```

- **ひとりぶん（raizin / moriken）は、1つで意味が通る文に。**
  「今日は何を作る？」のように返事を待つ形は宙に浮きます。疑問符で終わると自動検査で弾かれます
- **かけあい（pairs）は問いかけと返事にできます。**
  2つの吹き出しは同時に出るので、どちらが先かは気にしなくて大丈夫です
- `pairs` に `raizin` / `moriken` 以外のキーを足すと弾かれます（1往復を超えるため）
- `\n` で改行できます。吹き出しは幅が狭いので2行くらいが目安
- 同じ文・同じかけあいを二度書くと弾かれます
- `chats` は2行以上。`id` は重複できません。`title` は保管用で、画面には出ません

## 挙動

せりふは**画面下中央の共通ウィンドウ1枚**に出ます（2026-08-19に、左右の吹き出しから変更）。

- 1度に出るせりふは**1つだけ**。かけあいは1せりふ目 → 2せりふ目と入れ替わります
- 4〜6秒で次へ進み、会話が終わると10〜20秒黙ってから次の会話を始めます
- ウィンドウか立ち絵を押すと**早送り**できます。押さなくても進みます
- **× で閉じられます。** 以後そのタブでは**自分からは出てきません**（`sessionStorage` の `ls-talk-closed`）。
  それでも立ち絵を押せば、そのときだけ1会話出ます
- お問い合わせ欄とフッターが画面下部に来ると、邪魔しないよう黙ります
- 立ち絵は薄くしません。喋っている側だけ、ほんの少し大きくなります
- キーボードでも操作できます（Tabで立ち絵へ、Enter / Space）
- `prefers-reduced-motion` のときは動きを抑えます

立ち絵は出入りしません。**そこにいるまま**で、ウィンドウだけが現れて消えます。
